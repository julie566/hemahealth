# HemaHealth

> university project, archived. 

a mobile AR learning app about sickle cell disease. people compare healthy and sickle red blood cells as 3D models, then test what they've learned with a short quiz.

**[→ view the live project](https://julie566.github.io/hemahealth/)**

| | |
|---|---|
| **Role** | product design, UI kit, HTML prototypes |
| **Platform** | iOS / Android, AR built in Unity |
| **Stack** | Figma → HTML/CSS prototypes → Unity (TextMeshPro) |

## What's inside

| screen | sescription |
|---|---|
| [app mockup](https://julie566.github.io/hemahealth/mockup.html) | Main menu, AR module, cell views, 2D mode, quiz, profile |
| [UI kit](https://julie566.github.io/hemahealth/ui-kit.html) | Tokens, type scale, spacing, components, with Unity mappings |
| [Knowledge quiz](https://julie566.github.io/hemahealth/quiz.html) | Overview with 3D cells, then 5 questions with instant feedback |
| [2D explainer](https://julie566.github.io/hemahealth/explainer.html) | Flat, labelled version for people who don't use AR |

## design decisions

- **compare** the two cells sit side by side, and the difference in shape carries the explanation.
- **AR is optional** Every AR module has a 2D path.
- **one token set, two platforms** the HTML prototypes and the Unity build use the same tokens.
